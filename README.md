# Taneesh Web App (mock)

Веб-версия вкладок из `taneesh-app-ui` — **только реальные экраны**, без выдуманных блоков.  
Светлая витрина по `docs/DESIGN-SYSTEM.md`: `#3DC564`, canvas `#FFFFFF`, сетка 4 pt, радиусы 8/12/16/32.

| Страница | Файл | Как в приложении |
|----------|------|------------------|
| Главная | `index.html` | баннеры → Мои подборки → Новые профили → Бесплатные → Комментарии → Все мероприятия |
| Рядом | `near.html` | app bar (карта + фильтр) → крупные карточки событий |
| Избранное | `favorites.html` | табы **Мероприятия / Люди** → grid |
| Люди | `people.html` | app bar + фильтр → grid профилей |
| Чат | `chats.html` | **Интересуются вами** → список чатов |

Нижняя навигация: Главная · Рядом · Избранное · Люди · Чат

## Запуск локально

```bash
python3 -m http.server 5173
```

Открой http://localhost:5173
